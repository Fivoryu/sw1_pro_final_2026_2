# Avance por historias de usuario

Esta sección registra las historias de usuario que cuentan con evidencia disponible, organizadas por sprint. Actualmente, seis historias (HU-001, HU-002, HU-004, HU-005, HU-006 y HU-008) cuentan con evidencia de completitud técnica. El registro sigue siendo parcial: la verificación técnica de una implementación no equivale por sí sola a la ejecución del caso de prueba académico ni al cierre global del sprint.

## Leyenda de estados

- **Completada con verificación técnica:** existe evidencia verificable de implementación y validación técnica, ya sea en una slice backend/API o en un paquete OpenSpec de verificación. No equivale a validar todas las plataformas ni a ejecutar automáticamente el caso de prueba académico correspondiente.
- **Implementada por superficie:** se observó implementación o verificación parcial en una superficie concreta, pero permanece pendiente el cierre formal, la cobertura integral o la evidencia del caso de prueba académico.
- **Pendiente:** no existe evidencia suficiente de implementación y/o ejecución para registrar la historia como completada.

## Seguimiento por sprint

- [Sprint 1](sprint-1.md): seis historias cuentan con verificación técnica; HU-007 y otras historias tienen implementación parcial por superficie; el sprint permanece globalmente abierto.

- [Sprint 3](sprint-3.md): HU-003 cuenta con evidencia de verificación en la superficie backend, pero no se registra como una HU completada formalmente.

Las nuevas entradas deben indicar el alcance de la evidencia, el caso de prueba académico relacionado y los enlaces a los artefactos disponibles. Los paquetes de verificación técnica no deben presentarse como sustitutos de los registros académicos de pruebas.

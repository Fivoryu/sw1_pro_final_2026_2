# PROCESO DE DESARROLLO SCRUM

RoomForge se desarrolla con **Scrum** sobre un proyecto académico de 2,5 meses con equipo de seis integrantes y capacidad base de 20 horas-persona semanales.

## Marco de trabajo

- **Roles**: Product Owner, Scrum Master y equipo de desarrollo multidisciplinario (detalle en [Sprint 0 — Equipo Scrum](sprint-0-requerimientos/03-equipo-scrum.md)).
- **Artefactos**: Product Backlog ([S0-06](sprint-0-requerimientos/06-product-backlog-hu.md)), Sprint Backlog y Definición de Terminado (DoD) por sprint.
- **Ceremonias**: Sprint Planning, Daily Scrum, Sprint Review y Sprint Retrospective (registradas por sprint; sin evidencia aún → GAP-087).
- **Duraciones propuestas**: tres sprints de desarrollo (ver [S0-08](sprint-0-requerimientos/08-planificacion-de-sprints.md); fechas concretas → GAP-084).

## Capítulo 2 — Proceso de desarrollo de software (Sprint 1–3)

Cada sprint repite las mismas ocho secciones: Sprint Planning · Proceso/patrón por HU (Diseño: arquitectura, datos y lógica de negocio; Implementación; Pruebas) · Daily Scrum · Sprint Review · Sprint Retrospective · Burndown/BurnUp · Esfuerzo · Scrum Taskboard.

| Sprint | Foco propuesto | Estado |
| --- | --- | --- |
| [Sprint 1](../scrum/sprint-1/01-sprint-planning.md) | Fundaciones: identidad, suscripción, agentes, publicaciones, entorno local | planned |
| [Sprint 2](../scrum/sprint-2/01-sprint-planning.md) | Núcleo 3D y comercial: captura, pipeline, worker, precios, reservas | planned |
| [Sprint 3](../scrum/sprint-3/01-sprint-planning.md) | Cierre: correo real, acceso temporal, notificaciones, exportación, AWS | planned |

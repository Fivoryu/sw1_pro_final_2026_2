# T3 — Verificacion de camara y galeria en un dispositivo Android

Fecha: 2026-10-15. Grupo #12, SW1 2026-2.
Dispositivo: SM_S711B (Android), serie adb R5CWA0BTAKH.
APK: app-debug.apk (build debug) compilado con ROOMFORGE_API_BASE_URL=http://127.0.0.1:8000

## Por que tuneles y no la red local
Telefono 192.168.0.14 y equipo 192.168.0.30 estan en la misma /24, pero la Wi-Fi tiene
aislamiento de clientes: abrir http://192.168.0.30:8000/health/ready en el navegador del
telefono devuelve ERR_ADDRESS_UNREACHABLE. El firewall de Windows no bloquea: la red esta
clasificada como Publica y Docker Desktop tiene reglas Allow para ese perfil. La via que
funciona es el tunel USB y hacen falta los DOS puertos, la API 8000 y el almacenamiento
4566, porque el enlace de subida se firma con S3_PUBLIC_ENDPOINT_URL=127.0.0.1:4566.
